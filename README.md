# Agent Runtime

An independent, extensible agent runtime project, implemented in Rust.

The initial product specification and plan are in [`specs/001-agent-runtime/`](specs/001-agent-runtime/).
The project takes inspiration from Pi's minimal, extensible agent harness and spaex's composable,
versioned project harnesses, while making bounded subagent orchestration a core capability.

This repository currently contains specification and planning artifacts. Implementation has not started.
